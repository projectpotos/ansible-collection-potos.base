*****************************
potos.base.potos_set_password
*****************************

**Set a local user's password using chpasswd**


Version added: 0.1.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Sets the password of an existing local user
- This module is not idempotent. ``chpasswd`` cannot report whether the password already matched, so the task always reports ``changed=true``.

Examples
--------

.. code-block:: yaml

    - name: Set the operator's password
      potos.base.potos_set_password:
        name: operator
        password: "{{ chosen_password }}"
      no_log: true

    - name: Rotate the admin account to a random password
      potos.base.potos_set_password:
        name: admin
        generate: true
      register: rotated
      no_log: true
