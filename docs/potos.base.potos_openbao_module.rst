************************
potos.base.potos_openbao
************************

**Interact with OpenBao KV engine**


Version added: 0.1.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Wraps the ``bao`` CLI to interact with KV secrets.
- Supports OIDC device-code logins with a callback notification of the verification URL and user code.

Examples
--------

.. code-block:: yaml

    - name: OIDC device-code login
      potos.base.potos_openbao:
        action: login
        url: https://bao.example.com
        role: device
        callback_mode: device
        callback_host: localhost
        listen_address: 127.0.0.1
      register: bao

    - name: Read the specs token
      potos.base.potos_openbao:
        action: kv_get
        url: https://bao.example.com
        token: "{{ bao.token }}"
        path: kv/potos/specs
        field: token
